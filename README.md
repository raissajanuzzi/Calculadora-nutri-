# Calculadora da Nutri

Conversor de alimentos crus para cozidos, grelhados, assados, refogados e air fryer.

## Publicar no GitHub Pages

1. Crie um repositório novo (pode ser público) — sugestão de nome: `calculadora-nutri`.
2. Envie **todos os arquivos desta pasta** para a raiz do repositório (botão *Add file* → *Upload files*, arraste tudo, depois *Commit changes*).
3. No repositório, vá em **Settings** → **Pages**.
4. Em *Source*, escolha **Deploy from a branch**; em *Branch*, escolha `main` e a pasta `/ (root)`. Salve.
5. Aguarde cerca de um minuto. O endereço aparece no topo dessa mesma página: `https://SEU-USUARIO.github.io/calculadora-nutri/`

## Instalar no celular

Abra o endereço no navegador do celular:

- **iPhone (Safari):** botão Compartilhar → *Adicionar à Tela de Início*
- **Android (Chrome):** menu ⋮ → *Instalar aplicativo* ou *Adicionar à tela inicial*

Depois de instalado funciona offline.

## Atualizar

Suba os arquivos novos por cima dos antigos no mesmo repositório. O app busca sempre a versão mais recente quando há internet.
